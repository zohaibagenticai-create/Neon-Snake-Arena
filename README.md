# Neon Snake Arena

A premium web-based Snake game built with pure HTML, CSS, and JavaScript.

## Features

- Professional landing page
- Glassmorphism cyberpunk UI
- Canvas-based gameplay
- Classic, Maze, Infinite World, and Arena maps
- Power-ups: Speed Boost, Slow Motion, Double Score, Shield, Magnet Food
- Boss Challenge, Daily Challenge-ready, Survival, and Time Attack modes
- Local leaderboard
- Player nickname system
- PWA support
- Offline playable
- Mobile touch controls
- Ready for GitHub Pages, Netlify, or Vercel

## Run locally

Open `index.html` in a browser, or use a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deploy

Upload all files to GitHub Pages, Netlify, or Vercel as a static website.
